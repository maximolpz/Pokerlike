# Póker Roguelike (clon de Balatro)

Juego web (`index.html` + sonidos `Logo_pixelado_PokerLike.png`, `compra.mp3`, `ganar.mp3`, `derrota2.mp3`), sin dependencias. Subí todos los archivos juntos al repositorio.

## Cómo jugar
- Selecciona hasta 5 cartas y pulsa **Jugar mano** para formar una mano de póker.
- Puntos = (fichas base + fichas de las cartas que puntúan) × multiplicador.
- Supera el objetivo de cada ciega con 4 manos y 3 descartes.
- Entre ciegas visita la **tienda**: compra Jokers (máx. 5) y Planetas (suben de nivel una mano).
- Sobrevive 8 antes (pequeña, grande y jefe en cada uno) para ganar.

## Publicar en GitHub Pages
1. Crea un repositorio y sube `index.html` y este `README.md`.
2. Settings → Pages → Branch `main` / carpeta `/ (root)` → Save.
3. Tu juego estará en `https://TU_USUARIO.github.io/NOMBRE_REPO/`.
